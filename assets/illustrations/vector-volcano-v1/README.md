# Vector volcano — v1 (M2.5 style spike)

Hand-authored original flat-vector SVGs, written directly as code for the M2.5 style comparison. No image generation, no external source, no paid service.

| File | Canvas | Role |
| --- | --- | --- |
| `sky.svg` | 1080 × 1920, opaque | Dusk backdrop: gradient sky, sun, layered ridges, ground, foreground rocks |
| `cone.svg` | 1000 × 1300, transparent | Exterior cone with lit/shaded faces, gullies and crater |
| `cutaway.svg` | 1000 × 1300, transparent | Cross-section: strata, underground block, chamber cavity, conduit channel |
| `chamber.svg` | 1000 × 1300, transparent | Glowing magma body placed in the chamber cavity |
| `crater-glow.svg` | 1000 × 1300, transparent | Molten glow inside the crater during eruption |
| `rim-front.svg` | 1000 × 1300, transparent | Front crater lip drawn over the smoke column so it emerges from inside |

All transparent layers share one 1000 × 1300 canvas, so registration is exact by construction (crater centre 500,262; cone base y≈800; chamber centre 500,1060). Animated magma, lava, smoke and ejecta are procedural effects in the storyboard, not baked into these files.
